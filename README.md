# SQL Data Analytics Project #

## Overview

This project demonstrates SQL-based exploratory data analysis (EDA) and business analytics using a structured dataset. The scripts are organized in a logical sequence, starting from database exploration and progressing to advanced analytical reports.

## Project Structure

| Script                             | Description                                                                    |
| ---------------------------------- | ------------------------------------------------------------------------------ |
| `01_database_exploration.sql`      | Explore the database structure, schemas, tables, and row counts.               |
| `02_dimension_exploration.sql`     | Analyze dimension tables and understand categorical data.                      |
| `03_date_range_exploration.sql`    | Examine date ranges, data availability, and time coverage.                     |
| `04_measure_exploration.sql`       | Explore numerical measures and key metrics.                                    |
| `05_magnitude_analysis.sql`        | Analyze the magnitude of sales, revenue, quantity, or other business measures. |
| `06_ranking_analysis.sql`          | Rank products, customers, or other entities using SQL ranking functions.       |
| `07_change_over_time_analysis.sql` | Analyze trends and performance changes over time.                              |
| `08_cumulative_analysis.sql`       | Calculate running totals and cumulative metrics using window functions.        |
| `09_performance_analysis.sql`      | Evaluate business performance through KPIs and comparative analysis.           |
| `10_part_to_whole_analysis.sql`    | Measure each category's contribution to the overall business.                  |
| `11_data_segmentation.sql`         | Segment customers or products based on business rules and metrics.             |
| `12_report_customers.sql`          | Generate customer-focused analytical reports.                                  |
| `13_report_products.sql`           | Generate product-focused analytical reports.                                   |
